# Telegram Bot

Простой Telegram-бот для управления списком задач, написанный на Go. Бот позволяет совершать различные манипуляции с задачами. Данные хранятся в памяти, при перезапуске задачи не сохраняются. Проект создан для демонстрации навыков работы с Go и Telegram Bot API.

## Возможности

- Добавление задачи: `/add <текст>`
- Просмотр всех задач: `/list`
- Отметка задачи выполненной: `/done <id>`
- Удаление задачи: `/delete <id>`
- Справка: `/help`
- Приветствие: `/start`
- Обработка сообщений в отдельных горутинах

## Что необходимо

- Токен бота Telegram (получить у [@BotFather](https://t.me/BotFather))
- Доступ к `api.telegram.org` (при необходимости — VPN или прокси)
